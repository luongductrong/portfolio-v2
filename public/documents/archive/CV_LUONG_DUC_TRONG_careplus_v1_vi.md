## TÓM TẮT CHUYÊN MÔN

Là lập trình viên Frontend (Junior) với gần 2 năm tham gia xây dựng và cải tiến các ứng dụng web đang vận hành bằng React, Next.js và TypeScript. Thế mạnh tập trung vào xây dựng thành phần UI tái sử dụng, phát triển giao diện thích ứng (responsive), tích hợp REST APIs, quản lý trạng thái phía client và dữ liệu phía server. Có khả năng tiếp quản codebase, xử lý vấn đề frontend độc lập và phối hợp trong quá trình phát triển sản phẩm. Định hướng tiếp tục nâng cao chất lượng mã nguồn, hiệu năng và trải nghiệm người dùng cho các ứng dụng web thực tế.

## KỸ NĂNG CHUYÊN MÔN

- **Frontend:** JavaScript ES6+, TypeScript, React, Next.js, Vue.js, Nuxt, HTML5, CSS3
- **UI & styling:** Tailwind CSS, shadcn/ui, Ant Design
- **Trạng thái & tích hợp:** TanStack Query (React Query), Zustand, REST APIs, Axios, SAP OData
- **Công cụ & nền tảng:** Git, GitHub Actions, Vite, pnpm, PostgreSQL, SQLite
